# ✨ Overview

SB ChatBot is a modern AI-powered desktop chatbot application built using:

- 🐍 Python
- 🎨 CustomTkinter
- 🤖 Groq API
- ⚡ LLaMA 3.3 70B Model

This chatbot provides a beautiful ChatGPT-style interface with real-time AI conversations, typing effects, threading support, and a clean modern desktop experience.

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone  https://github.com/Ali-Ashor/Chat-Bot-AI-Project-.git
```

---

## 2️⃣ Open Project Folder

```bash
cd sb-chatbot
```

---

## 3️⃣ Install Dependencies

```bash
pip install customtkinter
pip install groq
```

---

## 4️⃣ Add Your Groq API Key

Replace this line:

```python
api_key="Enter your API"
```

With your actual Groq API key.

---

## 5️⃣ Run Application

```bash
python app.py
```

# 🧠 How It Works

## 🔹 User Input
Users type messages in the input field.

## 🔹 AI Processing
The message is sent to the Groq LLaMA 3.3 model.

## 🔹 AI Response
The AI generates a response in real time.

## 🔹 UI Update
Responses are displayed instantly inside the chat area.
